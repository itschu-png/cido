당신의 온도는 몇 도인가요?

5~7개의 문항을 통해 사용자의 피부 톤,

20°C ~ +38°C 사이의 결과값을 제공합니다.

진단시작 >

온도 유형 소개

진단 시스템은 피부 톤의 보색 원리와 색채 심리학
그리고 열역학적 무드 해석을 결합한 Thermal-Logic™ 알고리즘을 기반으로 합니다.

Type 01

[-20°C] FROZEN

안색 분석 : 혈색이 거의 비치지 않을 정도로 창백하며, 푸른 혈관이 비치는 매우 밝은 베이스입니다. 노란 기운이 1%만 섞여도 안색이 급격히 칙칙해지는 민감한 투명도를 가졌습니다.
Psychology : 이성적, 고결함, 접근하기 어려운 우아함.
Type 02

[-10°C] ASH MUTE

안색 분석 : 전체적으로 회색빛(Greyish)이 감도는 차분한 톤입니다. 붉은기가 피부 안쪽에 숨어 있어, 온도가 조금만 올라도 얼룩덜룩해 보일 수 있는 '안개 같은' 피부입니다.
Psychology : 지적인, 내성적인, 세련된 도시의 새벽.
Type 03

[0°C] BARE ZERO

안색 분석 : 노란기와 붉은기가 황금 비율로 섞인 정석적인 뉴트럴 톤입니다. 주변 빛이나 옷의 색상에 따라 온도가 쉽 게 동기화되는 가장 유연한 도화지 같은 상태입니다.
Psychology : 순수함, 신뢰감, 본질적인 아름다움.
Type 04

[+10°C] AMBER WARM

안색 분석 : 건강한 멜라닌의 기운이 느껴지는 따뜻한 베이 스입니다. 햇살 아래에서 가장 아름답게 빛나며, 골드 펄이 나 피치 계열을 올렸을 때 안색에 즉각적인 조명이 켜지는
타입입니다.
Psychology : 친근한, 에너제틱, 건강한 아름다움.
Type 05

[+38°C] FEVER

안색 분석 : 혈류량이 느껴지는 붉은 기운이나 깊은 구릿빛 안색을 가진 고채도 타입입니다. 색감이 진할수록 피부가 건 강해 보이며, 연한 파스텔 톤은 오히려 피부를 들떠 보이게 만듭니다.
Psychology : 열정, 과감함, 압도적인 존재감.
